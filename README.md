# Library Tab

Firefox extension: your new tab as a personal library — a wallpapered start page with a
files-and-folders manager for tabs, bookmarks and history, one-click **save to Notion**
(quick links or full AI summaries with images), rich site icons, hot apps, and backups.

- **[docs/SETUP.md](docs/SETUP.md)** — connecting Notion, AI keys (Anthropic/OpenRouter),
  rich icons, Firebase sync, backups, and how the save model works
- **[docs/RELEASING.md](docs/RELEASING.md)** — the full release runbook (package → AMO
  signing → GitHub release), golden rules, and troubleshooting

Distribution: signed via AMO (self-distributed channel); signed `.xpi` files are attached
to [GitHub releases](https://github.com/shivam1410/Firefox-extention---new-tab/releases).

## Reproducing the build (for AMO reviewers)

Environment used: macOS, Node.js v20.20.2, npm 10.8.2.

```bash
npm ci          # installs exact dependency versions from package-lock.json
npm run build   # TypeScript + Vite → dist/ (minification disabled in vite.config.ts)
```

The uploaded package is exactly the contents of `dist/` (`npx web-ext build --source-dir dist`).
Icons under `public/icons/` are generated by `node scripts/gen-icons.mjs` (deterministic, no deps).
No external services, no remote code, no data collection.

## Develop

```bash
npm install
npm run build        # one-shot build into dist/
npm run dev          # rebuild on change
npm run typecheck    # tsc --noEmit
npm run lint:ext     # web-ext lint against dist/
```

## Run in Firefox

Option A — throwaway profile with auto-reload:

```bash
npm start
```

Option B — your own Firefox:

1. Open `about:debugging#/runtime/this-firefox`
2. Click **Load Temporary Add-on…**
3. Pick `dist/manifest.json`
4. Open a new tab — that's the extension. The toolbar puzzle-piece button opens the Explorer.

Temporary add-ons unload when Firefox quits; reload them the same way. (Permanent install
requires signing through addons.mozilla.org — worth doing once the MVP is complete.)

## Layout

- `public/manifest.json` — MV3, event-page background, `chrome_url_overrides.newtab`
- `app.html` + `src/app/` — the single app page: `#/home` (new tab) and `#/explorer` (manager)
- `src/background/` — event page (toolbar action; later: metadata pipeline, hot-app warm-up)
- `src/core/` — (from P1) browser-API-free logic: IndexedDB store, tree ops, source adapters
